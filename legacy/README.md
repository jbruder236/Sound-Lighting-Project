# Earlier experiments

Archived code, reference images, and notes from the original sound-lighting project.
Kept for history and inspiration; the maintained programs live in
[`../RpiLightStripCodes/`](../RpiLightStripCodes/).

These scripts are deprecated. Many assume GPIO18, a default microphone, older
Python APIs, or non-addressable PWM hardware. Do not run them alongside the current
lighting service. Relative paths and dependencies may need repair before reuse.

The original local audio tuning and `lighty.py` are preserved here.
